# sim — 本地游戏模拟器 + mock 判题器（工作包 3）

《未来战争》规则的**可扩展、明确简化子集**。用于本地回归与自对弈，
**不追求与官方判题器 100% 一致**（.omo/plans/future-war-bot.md 工作包 3）。
仅用标准库，无第三方运行时依赖；同 seed + 同 Bot 动作序列 → 输出逐字节一致。

## 模块结构

| 模块 | 职责 |
| --- | --- |
| `rules.py` | 规则常量（属性表/商店价格/时间常量）+ 几何纯函数（切比雪夫/弹道/锥形判定） |
| `layout.py` | 合成地图：基地/蓝黄可建造区/固定中立单位/机器人出生候选格 + 矿区随机选址 |
| `world.py` | 世界状态容器（双方单位/机器人/矿区/回合计数器）与占用/视野查询 |
| `commands.py` | 指令结构性校验（§八「指令错误」口径） |
| `actions.py` | 非战斗指令执行（移动意图 + 采集/贩卖/购买/建造/拆除/丢弃/使用） |
| `combat.py` | 武器攻击校验与命中解析（加特林/电磁炮/火箭）+ 回合末伤害结算 |
| `robots.py` | 机器人波次生成/清除 + 贪心寻路与攻击阻挡单位 |
| `engine.py` | 回合编排（结算顺序、移动碰撞 §4.5.4、矿区存量聚合） |
| `protocol.py` | Bot 适配（进程内 callable / HTTP）+ 响应解析（§八三类异常口径） |
| `score.py` | 积分（score1/2/3）与胜负判定（§六/§七） |
| `judge.py` | mock 判题器：构造 Request、驱动双方、统计异常、回放/日志、分数报告 |
| `bots.py` | 演示 Bot：`IdleBot`、`ScriptedBot`（朴素防御） |

## 已实现规则（对齐任务书）

- 地图 41×32；蓝区只建武器、黄区只建围墙；矿区不在可建造区、每矿 10 次
  采尽后下回合随机刷新；不足平分时每工人各得 1（§4.1）。
- 时间：白天 70 + 夜晚 60 = 130 回合/天，上限 1300 回合（§4.2）。
- 视野：己方单位视野 4 全局共享；机器人全图可见；敌方基地/围墙全局可见（§4.3）。
- 角色：开拓者 HP200/背包40、工人 HP220/背包100；基地 2×2 HP1500；初始金 75；
  角色阵亡后次日白天开始后 20 回合在基地复活、背包保留（§4.5.2/§4.5.3）。
- 移动：8 方向、切比雪夫距离；目标受阻/目标争夺/位置互换三类碰撞，
  与角色碰撞双方停留、与障碍物碰撞仅移动方停留（§4.5.4）。
- 采集（矿区周围 1 格，矿石×1）、贩卖（小贩周围 1 格，基础价 1/3/5）、
  购买（武器商店周围 1 格，全部商品价格按接口样例）（§4.4/§4.6）。
- 建造：武器（蓝区，25 金，全局最多 3 座，覆盖同格旧武器）与围墙（黄区，
  1 石头）；仅工人、仅白天；拆除围墙（不回收石头）（§4.4/§4.5.1）。
- 攻击：仅夜晚；需操控角色在武器周围 1 格；一个角色一回合只能操控一座武器；
  目标位置数与武器等级一致（电磁炮恒 1）；伤害回合末统一结算；
  攻击 > 机器人移动的结算次序（§4.4/§4.5.4）。武器语义：
  - 加特林：每目标一颗子弹（10 伤害），命中弹道上最近机器人即消耗；
    多目标须落在同一 90° 锥内，否则整次攻击非法。
  - 电磁炮：能量 = 10×等级，沿弹道依次对机器人造成 min(剩余能量, 其血量)，
    能量耗尽或到达终点即止。
  - 火箭：每目标一枚导弹，中心 20、8 邻格溅射 10，落点重叠伤害叠加；
    发射后 3 回合冷却；导弹不被阻挡。
- 机器人（§4.7.2 属性）：夜晚第 1 回合统一生成、次日早第 1 回合清除；
  攻击阻挡其移动的单位；召唤令叠加到基础浪潮（§4.7.3）；
  **被眩晕时连续 5 回合不动也不攻击**（§4.6.3），`abnormalState="dizzy"` 会
  通过 Request 暴露给 Bot。
- 积分（§六）：score2 = Σ击杀×机器人积分；score3 = Σ 10×day×存活系数；
  score1 恒 0（stub）。胜负（§七）：基地先后被毁先毁者负、同回合同分平局、
  否则积分高者胜；1300 回合/双方基地被毁/双方异常各 5 次结束。
- 队伍异常（§八）：超时/格式错误/指令错误三类，每回合至多计 1 次，累计
  5 次后不再调度该队代码；规则性失败（碰撞/落点无目标/金币不足等）仅该
  指令无效、不计异常。

## 简化与偏离（显式清单）

1. **合成地图**：任务书仅给地图尺寸与图片，无坐标表。蓝/黄可建造区与机器人
   出生候选格为自定；基地 (10,24)/(30,10)、小贩 (20,16)、武器商店 (25,20)、
   任务点坐标对齐 docs/request.txt 样例。角色出生在各自蓝区内（自定）。
2. **机器人规则未定义部分**（§4.7.3）自定：
   - 数量曲线：第 N 天夜晚 小 = 2+N、中 = max(0,N-1)、大 = max(0,N-3)、
     BOSS = 1（N≥6）。
   - 出生：从目标基地一侧地图边缘的候选格随机（种子确定）。
   - 寻路：每回合贪心朝目标基地走 1 格；下一步被单位占据则攻击该单位；
     被中立/矿区阻挡则绕行；机器人不互相阻挡；机器人对「任何」阻挡单位
     攻击（不区分目标阵营）。
3. **结算次序补充**：任务书只规定「武器攻击 > 机器人移动」；角色移动与
   机器人移动的相对次序未定义，本模拟器取「机器人先动、角色后动」——
   机器人让出的格子角色可进入，机器人被静止角色阻挡则攻击之。
4. **弹道语义简化**：围墙/建筑**不阻挡**加特林与电磁炮弹道（方案 §3.2
   「墙后武器输出」的前提）；加特林/电磁炮**只对机器人**生效；火箭可命中
   任意单位（机器人/敌方角色/敌方建筑/围墙/基地），溅射不打己方单位；
   敌方单位不阻挡弹道。
5. **攻击命中判定**：以攻击解析时（机器人移动前）的单位位置确定命中对象，
   伤害在回合末结算（§4.4）；机器人移动后伤害仍施加于命中对象（文档化选择）。
6. **机器人攻击射程**：机器人攻击距离 3 仅作为属性暴露，行为模型为
   「被阻挡才攻击相邻阻挡单位」，不做 3 格内主动开火（简化）。
7. **未实现（指令合法但判无效，不计异常）**：
   - 任务系统：acceptTask / submitAnswer / summonTreasure、playerTasks 为空；
   - 消耗品/升级券：Medicine（回满血）、WallFixer（修复周围 1 格内己方围墙）、
     **Bomb（3×3 内 100 伤害）与 DizzyWeapon（3×3 内眩晕 5 回合）**生效；
     升级券不生效、建筑/武器等级恒为 1；
   - 世界新闻与矿石价格波动（价格恒为基础价）；LLM prompt 与沙盒 executeCmd
     直接忽略（响应中的这两个字段不校验、不生效）。
8. **超时**：连接/响应统一 5 秒（任务书区分连接 10s / 响应 5s，简化合并）。
9. **异常计数粒度**：同一回合内多条指令错误只计 1 次队伍异常（§八按「响应」
   计数，本文档化选择）。
10. **其他小简化**：角色复活于基地左上角（若被占不处理）；同格重砌围墙/武器
    沿用原 ID；矿区重生位置可压在角色/建筑上（角色可自行走开）；移动碰撞的
    「静止角色」判定仅看其本回合有无移动意图（极端换位叠加场景不做补偿）。

## 使用

```bash
python3 scripts/run_sim.py --seed 42 --challenger scripted:defense --defender idle
python3 scripts/run_sim.py --seed 42 --replay match.replay --log match.log
python3 -m pytest tests/test_sim.py -q
```

进程内驱动（测试/自对弈）：

```python
from future_war.sim import World, make_layout, run_match, bot_from_spec

world = World(seed=42, layout=make_layout())
report = run_match(world, {
    "challenger": bot_from_spec("scripted:defense"),
    "defender": bot_from_spec("idle"),
})
print(report.winner, report.teams["challenger"].total)
```

HTTP 驱动（集成）：`--challenger http:http://127.0.0.1:18080`（`bash run.sh 18080`
启动真实 Bot 服务后使用）。
