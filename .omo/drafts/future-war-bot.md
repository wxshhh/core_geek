## Findings (cited - path:lines)

- 胜负/积分：总积分=任务分+击杀分+生存分；生存系数=基地未被摧毁。docs/任务书.md §六/§七
- 时间：白天70+夜晚60=130回合/天，上限1300回合(10天)。docs/任务书.md §4.2
- 视野：己方单位视野4且共享；机器人全图可见；敌方基地/围墙全局可见。docs/任务书.md §4.3
- 动作结算：武器攻击 > 机器人移动；伤害回合末统一结算。docs/任务书.md §4.4
- 武器上限3座；火箭L3射程全图且导弹不被阻挡；电磁炮穿透；加特林90°锥形。docs/任务书.md §4.5.1/§4.5.4
- 角色：开拓者HP200/背包40，工人HP220/背包100×2；阵亡次日白天后20回合基地复活且保留背包。docs/任务书.md §4.5.2
- 机器人：小5/中10/大20/BOSS40攻击力，射程均3；积分1/2/4/10。docs/任务书.md §4.7.2
- 召唤令：给「对方」下个夜晚增加机器人，每天最多10张。docs/任务书.md §4.6.3
- LLM：每游戏日3次，自进化任务期间不限次且不计入；异步 prompt→llmResp。docs/接口文档.md §1.7
- 沙盒：executeCmd 仅在任务期间可用，≤15s，无外网；结果 [exitCode:N]/[TIMEOUT]/[TRUNCATED]。docs/接口文档.md §2.1
- 寻宝结果码：0未探测/1成功/2无宝藏或未开启/3献祭物品错误/4宝藏已空。docs/接口文档.md §1.1
- 异常：5s 响应超时；异常5次后不再调度；异常退出不再拉起。docs/任务书.md §八
- 角色ID固定：挑战者 worker1=10010/pioneer=10011/worker2=10012/station=10013，防御者200xx。docs/接口文档.md §1.3.1

## Decisions (with rationale)

1. 规则驱动主体 + LLM/沙盒仅用于三类认知任务（价格推理/寻宝推断/自进化解题），实时决策（寻路/经济/战斗）全部走自有确定性代码——因沙盒仅任务期可用且 LLM 有配额与1回合延迟。
2. 防御优先、进攻为辅：生存分550且基地被毁=判负，先保基地；火箭L3全图狙击作为低风险持续施压，落后时才升级为推家。
3. 武器组合默认 1 火箭 + 2 电磁炮，优先升火箭L3。
4. 先搭本地模拟器/mock 判题器，所有策略迭代在离线自对弈中回归。
5. 自进化任务做成通用 Agent 循环 + 技能库(SOP)，不硬编码具体任务。
6. 利用「任务期间 LLM 免费」窗口顺带做战略/寻宝分析。
7. **可观测性优先（用户工作流强约束）**：比赛在公司内网、数据不可外传、GitHub 是唯一通道、开发者看不到真实对局 → 代码必须自带固定格式日志 + 稳定事件码 + 比赛摘要 + 异常自检 + 配置中心 + 诊断字典/报告协议，使用户能用一句话反馈现象并定位到模块与参数。可观测性作为 Wave 0 前置工作包（5–8），并横切所有模块。

## Scope IN

- Python HTTP Bot：接口层、世界模型、规划器、寻路/碰撞、经济、战斗、建造、任务求解、寻宝、推理、LLM/沙盒管理、日志回放。
- 本地游戏模拟器 + mock 判题器 + 自对弈 + 记录回放。
- 三类任务的实现与联动。
- 进攻策略（火箭狙击/召唤骚扰/角色狙击）。
- 测试、容错、超时加固。

## Scope OUT (Must NOT have)

- 不做强化学习/神经网络训练（规则+启发式为主，LLM 仅认知任务）。
- 不依赖外网（沙盒无外网，Bot 也不假设外部服务）。
- 不硬编码具体任务答案/地图坐标（地图随机、任务动态）。
- 不牺牲健壮性换分数（任何未捕获异常导致进程退出=直接判负）。
- 不修改官方判题器/接口契约。
