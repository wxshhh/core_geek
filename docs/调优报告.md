## 二、发现

1. **能稳赢空 Bot**，但**打不过模拟器自带的 ScriptedBot**（0/5）。
2. **平均总分偏低（~84）**：满生存分应为 550（10 天），~84 说明基地在第 3–4 天即被
   机器人浪潮摧毁——**存活时长是最大短板**。
3. 机器人浪潮随天数增长；仅 3 座 1 级武器 + 无围墙，后期必然被淹没。

## 三、根因假设（待验证）

| 假设 | 依据 | 候选改动 |
| --- | --- | --- |
| 未建围墙，机器人直接打到武器/基地 | 经济只建武器、不建围墙（§3.1 建造顺序第 2 步未落地） | 经济增加「有石头且在黄区旁 → build wall」 |
| 石头优先级不足 | 采矿按「最近矿」分配，未为围墙预留石头 | 需要围墙时优先采石矿 |
| 武器前出但操控者够不着 | `preferred_weapon_cells` 偏好前出（离基地远） | 复核布局 vs 操控者可达性 |
| 夜晚回防时机 | 白天工人可能远离基地 | 参考 ScriptedBot 的 `DUSK_RETURN=40` 提前回防 |
| 升级链缺失 | 模拟器不支持升级券，武器恒 L1 | 真机可升 L2/L3 提升火力（本地测不了） |

## 四、改进待办（按 ROI 排序）

1. **建围墙**（最高 ROI）：经济模块增加围墙建造，石头优先；预期显著延长存活。
2. **提前回防**：白天后段（如第 40 回合起）工人撤回基地，保证夜晚有操控者。
3. **布局复核**：武器前出与操控者可达性权衡（当前前出可能不利于操控）。
4. **升级链**：真机环境验证升级券（本地模拟器 stub）。

## 五、结论

- **基线达标**：端到端可运行、能赢空对手、无队伍异常、可复现（工作包 13）。
- **竞争力不足**：存活时长是瓶颈，围墙与回防是下一步最高 ROI 的改动。
- 本报告作为后续 Wave 之外持续调优的起点；每次改动跑 `self_play.py` 对比胜率/均分。
