## 三、围墙：设计已落地，真机收益待验证

- 现状：`build.wall_enabled`（默认开）→ **只围三面 U 形**：来袭面优先，两个相邻面
  补齐，背面不建（`_side_tier` 用余弦判定，`cos < -0.5` 整段跳过）；来袭方向
  优先取机器人质心、其次敌方基地方向，**首次判定后锁定**。缺石先采石，
  `build.wall_probe_budget`（每天重置）限定探路次数，探明合法墙位后才常规铺设。
- 本地实测：**0 座**。原因是模拟器的**合成黄区**距离基地偏远且形状任意，
  方环候选先撞非法格用光探路额度 → 按设计退回纯武器防线。
  （旧版曾试过围墙并判定「中性」后回退，见下文「已试未采纳」。）
- 真机预期：真实黄区通常紧贴基地，方环内圈命中率应显著更高；真机日志里看
  `[BUILD] B-02`（建造受阻）与 `[METRIC]` 的围墙数即可判断。
- 回退方式：`build.wall_enabled=false` 一键退回纯武器防线。

## 五、改进待办（按 ROI 排序）

1. **真机校正推断半径**：第 1 天日志里若 `B-02` 密度高，说明
   `world.inference.blue_radius` 偏大；若建造位于色区外，调小。
2. **真机验证围墙收益**：对比 `build.wall_enabled` 开/关两版的存活天数与均分。
3. **金币转化率**：当前金矿往返小贩耗时长，升级券（100/150 金）落地慢；
   真机地图若小贩更近，`economy.dusk_return` 之后可再压榨一轮采集。
4. **任务/寻宝链路真机验证**：本地模拟器未实现任务与宝藏。
5. **验证召唤令收益**：真机看对方夜里的机器人数量是否随召唤增加
   （`[METRIC]` 的 robots 字段），以及击杀分 `score2` 的日增。

## 六、结论

- **第一晚的崩溃链已断**：3 座武器 + 3 名操控者 + 首晚基地近乎满血，4 seed 全部成立。
- **生存时长仍是瓶颈**：满生存分 550，当前均分 99~114，说明第 4~5 天起仍会被浪潮淹没
  （模拟器里升级券不生效，真机升级后应更好）。
- 本报告作为持续调优起点；每次改动跑 `self_play.py` 对比胜率/均分。
